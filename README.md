# Galera-do-Geracao-Caldeira-2026
Este é um repositório público em que os alunos participantes do Geração Caldeira 2026 podem compartilhar um pouco sobre si e expressar a sua paixão por programação.

## Como contribuir
1. Faça um fork deste repositório.
2. Crie um arquivo `.md` com seu nome dentro da pasta `/alunos`.
3. Adicione informações sobre você e envie um pull request.
